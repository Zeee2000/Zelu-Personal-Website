# Zelu's Portfolio Website

A modern, responsive portfolio website showcasing my professional journey and technical projects. Built with React, Three.js, and modern web technologies.

## 🛠️ Technologies Used

- React.js
- Three.js - 3D graphics and animations
- Tailwind CSS - Styling
- Framer Motion - Animations
- AWS SES - Contact form integration

## ✨ Features

- Interactive 3D elements
- Responsive design that works on all devices
- Animated project cards
- Professional experience timeline
- Contact form with AWS integration
- Smooth scrolling and animations
- Dynamic 3D airplane model in contact section

## 🔧 Setup and Installation

1. Clone the repository
```bash
git clone https://github.com/zelutesema/portfolio
```

2. Install dependencies
```bash
npm install
```

3. Run the development server
```bash
npm run dev
```

4. Build for production
```bash
npm run build
```
